# 8bercue 0.19.1-beta.4

本次更新新增 Shizuku 连接方式，并优化 eSIM 删除确认与返回导航体验。
版本：**0.19.1-beta.4** · versionCode：**49** · Android 9+ / ARM64。
功能代码基线：[227d9a0](https://github.com/woworz/8bercue/commit/227d9a0127e49d8040c7d0812368954bf426ab7b)。本次在此基础上仅更新版本号与发布资料。

## 新增 Shizuku 支持

- 可从首页“连接卡片”或设置中选择“通过 Shizuku 连接”，授权后在手机上启动卡片管理服务；原有电脑 ADB 连接方式继续保留。
- 提供未安装、服务未启动、版本过低、权限被拒绝及连接超时等状态提示，并在连接信息中显示连接方式。
- 需要 Shizuku API v12 或以上，以无线调试或 ADB 启动的 Shell 模式运行；暂不支持 Root 模式或 Sui。
- Shizuku 和 ADB 共用原有管理服务、卡片核验与恢复保护。授权成功不代表所有设备和卡片都已兼容。

## 删除与返回体验优化

- 删除前展示目标卡片、eSIM 名称和 ICCID，新增 **3 秒确认倒计时**；仅允许对满足删除条件的已停用配置继续操作。
- 删除确认前后核对当前页面、卡片列表和服务连接状态，避免使用过期页面提交删除。
- 返回键或返回手势优先关闭当前弹窗；从操作详情返回记录列表时保持合理的导航层级。
- 改进 Android 13+ 返回回调及旧版 Android 的返回处理，并在应用切入后台时关闭相关弹窗、使过期页面状态失效，恢复前台时刷新首页。
- 补充中英文删除倒计时提示。
